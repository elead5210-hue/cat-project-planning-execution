# PAT Phase 2 - Website

This folder holds the website for the PAT on the role of technology in combating climate change. It is part of the Phase 2b submission.

## What belongs here

- The skeleton website provided in the website folder of the PAT materials, which is the starting point for the site.
- The finished, fun and interesting climate-technology website that the school can use.
- Any images used on the site, saved in this folder so the pages display correctly when the folder is moved to the memory stick.

## What the website must contain

- A relevant title, shown in the title tag and as a heading on the page.
- An introduction explaining what climate change is and how technology helps to address it.
- A list of eco-friendly technologies, such as solar panels, wind turbines, electric vehicles, recycling technologies and smart farming tools.
- A list of the benefits of these technologies, such as reducing emissions, saving energy, protecting natural resources and promoting sustainability.
- At least one relevant image.
- A conclusion summarising why technology is important in solving environmental problems.

## Notes

- Use clean, valid and neatly indented HTML with the correct tags.
- Acknowledge the source of every image used.
- Open the pages after copying the folder to the memory stick to check that everything works.
