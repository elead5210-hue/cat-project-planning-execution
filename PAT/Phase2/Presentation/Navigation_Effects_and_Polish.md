## 3. Action buttons

Add the same three action buttons, in the same position and size, on slides 3 to 9. This is easiest to do once on the slide master (or copy and paste the buttons to each slide).

| Button | Action | Where it goes |
|---|---|---|
| Table of contents (Home) | Hyperlink to slide 2 | Slides 3 to 9 |
| Previous (Back) | Hyperlink to the previous slide | Slides 3 to 9 |
| Next (Forward) | Hyperlink to the next slide | Slides 2 to 8 |

- [ ] The Next button is also on slide 2, so that the presentation can continue from the table of contents (it goes to slide 3).
- [ ] The Previous button on slide 3 goes back to slide 2, and the Next button on slide 9 is left out because it is the last slide (the Home and Previous buttons remain).
- [ ] The buttons are the same size and in the same position on every slide, and do not cover any text or graph.
- [ ] Every button was tested in slide show mode.

## 4. Transitions

- [ ] Choose one transition and apply the same transition to every slide **except** the title slide (slides 2 to 9).
- [ ] Set the transition speed to fast (a short duration).
- [ ] The title slide (slide 1) has no transition.
- [ ] Do not use sound with the transition.

## 5. Animation

- [ ] Animate no more than one element on each slide.
- [ ] The animated element is not a heading (animate a bullet list, a picture or a graph).
- [ ] Use a simple, quick animation (for example fade or appear), and use the same one on every slide that has an animation.
- [ ] The animation starts in a way that does not slow down the presentation (for example on click, or after the previous element), and every animation was tested in slide show mode.
- [ ] Slides without animation are also fine; the limit is a maximum of one.

## 6. Language and spelling check

- [ ] Run the spelling and grammar check on all slides (including the text in the speaker notes, if any).
- [ ] Set the proofing language to English (South Africa) or the language used in the school.
- [ ] Correct all errors, and read each slide aloud once to find mistakes that the check misses (for example a correctly spelled but wrong word).
- [ ] Check that names, acronyms and technical words (for example IPCC, IEA, NASA, FAO, UNEP) are spelled correctly.
- [ ] Check that the 7x7 rule is still met after any corrections (no more than seven bullets per slide and seven words per bullet).

## 7. Design consistency and readability

- [ ] All slides use the same theme, colour scheme, fonts and bullet style.
- [ ] Headings have the same font, size and position on every slide.
- [ ] Body text is large enough to read from the back of a classroom (at least 24 pt is recommended), and headings are larger than body text.
- [ ] There is strong contrast between the text and the background (for example dark text on a light background, or the reverse), and the colours are not distracting.
- [ ] Graphs and images are clear, are not stretched or pixelated, do not overlap text, and each one has an acknowledged source.
- [ ] The slides are not crowded: there is enough white space around the text, the graphs and the buttons.
- [ ] Every slide has a title, and the slide numbers are in the same order as the table of contents.

## 8. Final test before submission

- [ ] Run the whole presentation in slide show mode from slide 1 to slide 9, using only the action buttons and the table of contents links.
- [ ] Confirm that all hyperlinks and buttons work.
- [ ] Save the presentation in `PAT/Phase2/Presentation` together with its linked files, and keep a backup copy.
