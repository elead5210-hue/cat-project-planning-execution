# PAT Submission Checklist

Use this checklist to back up and assemble the whole PAT folder on a memory stick, and to test it before it is handed in. Tick each box when it is done.

**Learner:** ____  **Grade:** ____  **Date:** ____

---

## 1. Check that all work is finished

- [ ] The Phase 1 research planning document is finished. It has the task definition, focus question, research questions, information sources, summaries, reference list and image sources.
- [ ] The questionnaire has been given to at least 10 learners, and all ten completed questionnaires are saved.
- [ ] The spreadsheet is finished. It has the captured data, the formulas and functions (including COUNTIF) on a separate worksheet, and at least two readable graphs on their own worksheet.
- [ ] The final presentation is finished, with the table of contents links, action buttons, one fast transition on slides 2 to 9, and at most one animation per slide.
- [ ] The website is finished (title tag and heading, introduction, list of technologies, ordered list of benefits, at least one image and a conclusion).
- [ ] The spelling and language check has been done in the document, the presentation and the website text.
- [ ] Every blank (____) in the files has been replaced with real information.

## 2. Check the declarations of authenticity

- [ ] The Phase 1 declaration is completed, signed and dated.
- [ ] The Phase 2a declaration is completed, signed and dated.
- [ ] The final declaration is completed, signed and dated.
- [ ] A scan or photograph of each signed declaration is saved in the correct folder (see section 3).

## 3. Check the folder structure

Everything must be inside one folder called `PAT`, in this structure:

```text
PAT/
  README.md
  Submission_Checklist.md
  Phase1/
    README.md
    Research_Planning_Document (the Phase 1 word processing document)
    Declaration_of_Authenticity_Phase1
    Research_Sources/   (copies of sources, saved web pages, copies of images)
    Questionnaires/     (blank questionnaire and the ten completed questionnaires)
  Phase2/
    README.md
    Spreadsheet/        (the Phase 2a spreadsheet and its graphs)
    Presentation/       (the final presentation)
    Declaration_of_Authenticity_Phase2a
    Declaration_of_Authenticity_Final
    Website/            (index.html, style.css, images and any other pages)
```

- [ ] Every file has a clear, meaningful name.
- [ ] The Phase 1 word processing document, the spreadsheet and the presentation are saved in their own file formats (for example Word, Excel and PowerPoint, or the formats your school uses), in the folders shown above.
- [ ] A screenshot of this folder structure is included in the Phase 1 document, as the Phase 1 README asks.

## 4. Check that the memory stick contains everything

- [ ] The questionnaires (the blank one and the ten completed ones).
- [ ] The electronic copies of the sources.
- [ ] The web pages used as sources.
- [ ] The word processing document for Phase 1.
- [ ] The spreadsheet for Phase 2a.
- [ ] The declarations of authenticity for Phase 1, Phase 2a and the final declaration.
- [ ] The final presentation for Phase 2b.
- [ ] The website folder, including its images and style sheet.
- [ ] Any hard-copy evidence that cannot be converted to electronic form has been scanned or photographed and saved, or is handed in as your teacher instructs.

## 5. Back up

- [ ] Make a backup copy of the entire `PAT` folder on a second device or location (for example another memory stick, an external drive or cloud storage), before copying anything to the submission memory stick.
- [ ] Keep the backup until your marks have been published.

## 6. Copy to the memory stick

- [ ] Copy the entire `PAT` folder (Phases 1 and 2) to the memory stick. Copy the whole folder so that the structure stays the same.
- [ ] Label the memory stick with your name, grade and class.
- [ ] Make sure that the memory stick has no virus and has enough free space.

## 7. Test on another computer

Test the memory stick on a computer other than the one you worked on.

- [ ] The memory stick is recognised and the `PAT` folder opens.
- [ ] Every file opens without errors, and the files open in the correct programs.
- [ ] The spreadsheet formulas still work and show values (not errors), and the graphs are still on their own worksheet.
- [ ] The presentation runs from slide 1 to the last slide. All hyperlinks and action buttons work, including the link to the `Research_Sources` folder, and the images and graphs are visible.
- [ ] The website opens by double-clicking `index.html`. The image is shown, the style sheet is applied, and every link works.
- [ ] The saved web pages and copies of sources open.
- [ ] The scans of the signed declarations can be opened and read.
- [ ] If anything failed, fix it on your own computer, recopy the folder, and test again.

## 8. Before you hand in

- [ ] Hand in the memory stick (and any hard copies) before the deadline given by your teacher. The deadlines for Phase 2a and Phase 2b are set by your teacher.
- [ ] Keep your backup safe.
