# PAT Phase 1 - Research sources

This folder holds the resources used for the Phase 1 research on the role of technology in combating climate change.

## What belongs here

- Electronic copies of the sources used (for example downloaded articles, reports and documents).
- The web pages used as sources, saved so they can be opened without the Internet.
- Copies of the images used, where possible.

## Notes

- Give every file a clear, meaningful name that shows what the source is about.
- Record the bibliographical details and the URL of each source and image in the Phase 1 research planning document.
- Hyperlinks in the final presentation can point to this folder.
