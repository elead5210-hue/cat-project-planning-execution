# PAT 2026 - Grade 10 Computer Applications Technology

Theme: The role of technology in combating climate change

Focus question: How is modern technology helping to reduce the effects of climate change, and which solutions are the most effective?

This folder holds all the evidence for the Practical Assessment Task (PAT). Keep everything in this structure so that the whole PAT can be found easily and submitted together on one memory stick.

## Folder structure

```text
PAT/
  README.md
  Phase1/
    README.md
    Research_Sources/
      README.md
    Questionnaires/
      README.md
  Phase2/
    README.md
    Website/
      README.md
```

## What each folder holds

- Phase1: the Phase 1 research planning (word processing) document and the Phase 1 Declaration of Authenticity.
- Phase1/Research_Sources: electronic copies of the sources used and the web pages used as sources.
- Phase1/Questionnaires: the blank questionnaire and the ten completed questionnaires.
- Phase2: the Phase 2a spreadsheet, the Phase 2b final presentation and the Phase 2 Declarations of Authenticity.
- Phase2/Website: the provided skeleton website and the finished climate-technology website.

## Checklist for the submission drive

Copy the entire PAT folder (Phases 1 and 2) to the memory stick. Make sure it contains:

1. The questionnaires (blank and the ten completed ones).
2. The electronic copies of the sources.
3. The web pages used as sources.
4. The word processing document for Phase 1.
5. The spreadsheet for Phase 2a.
6. The declarations of authenticity for Phases 1 and 2, including the final declaration.
7. The final presentation for Phase 2b.
8. The website folder.
9. Any hard-copy evidence that cannot be converted to electronic format, scanned where possible.

## Before you submit

- Back up all data before submitting it.
- Use clear, meaningful folder and file names.
- Test the memory stick on a computer other than the one you worked on, to confirm that all the data is on it.
- Keep to the deadlines for each phase. Phase 2a and Phase 2b are submitted together.
